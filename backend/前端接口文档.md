# AI 剧本引擎 - 前端对接文档

## 基础信息
- 服务器地址：`http://localhost:8000`
- 所有接口都是 POST 请求
- 返回数据格式：JSON 或 YAML
- 跨域已开启，前端可直接调用

---

## 接口 1：上传小说，生成剧本

**地址**：`POST http://localhost:8000/convert`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 小说文本文件（.txt） |
| title | String | 否 | 剧本标题，默认"未命名" |

**前端调用示例（TypeScript）**：
```typescript
const formData = new FormData();
formData.append("file", fileInput.files[0]);
formData.append("title", "雨夜访客");

fetch("http://localhost:8000/convert", {
    method: "POST",
    body: formData
})
.then(response => response.text())
.then(yamlText => {
    console.log(yamlText);  // YAML 剧本内容
    // 接下来可以传给 /analyze 做分析
});
```

---

## 接口 2：剧本分析

**地址**：`POST http://localhost:8000/analyze`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| yaml_text | String | 是 | 接口1返回的完整 YAML 文本 |

**前端调用示例（TypeScript）**：
```typescript
fetch("http://localhost:8000/analyze", {
    method: "POST",
    headers: {
        "Content-Type": "application/x-www-form-urlencoded"
    },
    body: new URLSearchParams({
        "yaml_text": yamlText  // 接口1拿到的 YAML 字符串
    })
})
.then(response => response.json())
.then(data => {
    console.log(data.角色冲突热力图);   // 画关系网络图
    console.log(data.节奏分析报告);     // 画折线图
    console.log(data.镜头语言汇总);     // 列表展示
    console.log(data.角色戏份平衡);     // 饼图或柱状图
    console.log(data.情绪曲线数据);     // 画情绪曲线图
});
```
