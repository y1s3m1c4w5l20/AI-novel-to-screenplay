# AI 小说转剧本引擎 - 项目文档

## 一、项目概述
将小说文本自动转换为结构化剧本（YAML 格式），降低改编门槛。

## 二、技术架构
小说文本 → 解析器切分章节 → AI 生成剧本 → 分析器诊断 → YAML + JSON

## 三、核心功能
1. 小说解析：自动切分章节、提取角色
2. AI 生成：调用 Kimi API，生成带镜头建议、潜台词的剧本
3. 剧本分析：冲突热力图、节奏分析、戏份平衡、情绪曲线

## 四、API 接口
- POST /convert：上传小说 → YAML 剧本
- POST /analyze：YAML 剧本 → JSON 分析数据

## 五、分工
- 引擎开发（我）：后端、AI 调用、Schema 设计、分析器
- 产品前端（同学）：Web 界面、可视化、联调

## 六、技术栈
Python + FastAPI + LangChain + Kimi API + Pydantic
